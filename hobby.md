# Мой пет-проект

**Идея:** платформа для деплоя и хостинга веб-приложений, которая позволяет пользователю
подключить Git-репозиторий, настроить переменные окружения, автоматически собрать проект
и развернуть его на сервере. Платформа должна предоставлять управление деплоями, логами,
доменами и состоянием запущенных приложений.

**Стек:** Go + React + TypeScript + Tailwind CSS + PostgreSQL + Docker

**Цель:** разобраться в устройстве современных PaaS-платформ и научиться проектировать
сложные fullstack-системы с нуля: работа с контейнерами, очередями задач, Git,
CI/CD-пайплайнами, reverse proxy, WebSocket/SSE для логов, базами данных и
инфраструктурой. Также углубить знания Go, React и TypeScript и получить практический
опыт построения масштабируемой архитектуры.

## Дорожная карта

### Этап 1 — Базовая архитектура
- Спроектировать структуру backend и frontend частей приложения
- Поднять API на Go
- Настроить PostgreSQL и миграции
- Реализовать базовые сущности: пользователь, проект, deployment
- Создать dashboard на React
- Настроить конфигурацию приложения и переменные окружения

### Этап 2 — Авторизация и проекты
- Регистрация и авторизация пользователей
- JWT или session-based аутентификация
- Создание и удаление проектов
- Настройки проекта
- Хранение переменных окружения
- Подключение Git-репозитория

### Этап 3 — Система сборки
- Клонирование Git-репозитория
- Определение типа проекта
- Создание Docker image
- Запуск build-процесса
- Сохранение статуса сборки
- Обработка ошибок сборки

### Этап 4 — Deployment
- Запуск собранного приложения в Docker-контейнере
- Управление жизненными состояниями контейнеров
- Автоматическое назначение портов
- Генерация уникального URL для deployment
- Stop / Restart / Redeploy
- Хранение истории deployment'ов

## Минимальная версия проекта

Первую рабочую версию стоит ограничить простым сценарием:

> Git-репозиторий → Build → Docker-контейнер → URL
